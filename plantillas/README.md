# Plantillas Excel

Ejecuta en Windows:

```bat
python generar_plantillas.py
```

Se crearan:

```text
equipos.xlsx
personal.xlsx
productos.xlsx
repuestos.xlsx
```

Columnas:

```text
equipos: codigo, ubicacion, proceso, sistema, equipo, componente, estado
personal: codigo, nombre, cargo, area, estado
productos: codigo, nombre, unidad, stock, estado
repuestos: codigo, nombre, unidad, stock, estado
```
